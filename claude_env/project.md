Project Purpose: 

Develop experience using AI coding partners to combine industry technologies in order to build a web application platform. Ultimately, the platform will feature:
1. A distributed system hosted in a cloud environment for scalability
2. Front end code
3. Back end code comprised of REST APIs and microservices written in Java
4. A database (SQL or noSQL, whatever is appropriate)
5. A business use case for generative AI
6. Any other critical peripheral technologies like authentication/firewalls/DDOS protection/etc

Project Idea:

A chess website tailored specifically for people interested in learning and practicing openings with the help of a generative AI coach. There are a plethora of easily accessible resources for learning new openings these days, however, chess players can’t discuss their individual experiences and challenges with the book they were reading or the youtube video they were watching. A chess engine will always be able to inform a player of the next best move, but engines can’t explain themselves to a human, rendering them a tricky resource to rely on for learning. By leveraging the wisdom that the chess community has gathered over the years, a generative AI coach can bridge the gap between knowing the next best moves, and understanding the ideas and reasonings behind them.

Project Milestones:
MVP - A webpage featuring various chess openings, their moves, and access to an AI coach that users can chat with.

V1 - A user account feature that allows users to create an account and have the system remember their favorite openings and their chats with the coach.

V2 - Users can upload games and write notes corresponding to each game which the system will remember.

Later - A practice feature allowing the user to play through one or more openings and variations with the coach in order to develop memorization and understanding.

Not in scope - An entire LLM trained specifically on chess opening theory that has been produced by the chess community over time.
